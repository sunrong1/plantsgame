## 什么时候移进来

条目在**活账本**里被结清（当场修掉 / 前提被推翻 / 被后续 story 吸收）时。
归档是收尾动作的一部分，不另开一次专门归档 —— 见 `docs/rules/process.md` R-43。

## 谁负责把它移进来

跟条目本身一样：**处理那个条目的 story**。归档是那个 story 的收尾动作，
不是一次单独的「整理归档」任务。
⚠️ 归档动作会触发**外来守卫**（R-40 的归档路径守卫等）—— 归档完成后必须跑全量测试。
