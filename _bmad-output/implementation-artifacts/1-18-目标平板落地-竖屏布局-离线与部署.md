### 裁决 4 —— 🔥 预取 vs 硬约束 8 的冲突：**解锁后再异步预检**（AC 逐字有偏差，如实记）

- **冲突逐字：** AC 要求「进入前**预取该单元全部图片并等待完成**，战斗中零加载停顿」。而 `enterLevel()`（`src/app/store.ts`）返回 `void`，被架构硬约束 8 锁死为同步 —— `src/app/audio-unlock.ts` 的注释逐字写着「本文件在解锁链路上，**不允许出现任何 `await`**」，且被 eslint 强制。
- **已登记的判据：** deferred-work 逐字写着「**机制上做不了**：判定「加载失败」要**异步预取**……而 `enterLevel()` 被架构硬约束 8 锁死为**同步** …… ⇒「进关时预检 30 张图」这件事**与解锁时序直接冲突，不是排期问题**」。
  [Source: `_bmad-output/implementation-artifacts/deferred-work.md`「词图预检缺口」段]
- **用户裁决（2026-10-17）：解锁后再异步预检。**
- **形状：**
  ```ts
  // src/app/store.ts —— enterLevel() 保持同步，一个 await 都不加
  export function enterLevel(): void {
    unlockAudioSequence()      // ① 三步同步解锁（不动）
    startLevel()               // ② 立即可玩
    void prefetchUnit(index)    // ③ 同步发起，不 await（与 audio.ts 的 fetchAudioBuffer 同一手法）
  }
  ```
- **⚠️ 与 AC 逐字有偏差，本文档不掩盖：** AC 说「进入前预取并**等待完成**」，本裁决是「进入**后**异步预取、预取未完成时卡面走 1.11 已建的占位/降级协议」。**理由是保住硬约束 8 与 AC-3s 冷启动**，两者都是更硬的约束。

- **两段进度必须诚实：** 「战斗中零加载停顿」在**第二次**进入同一单元时成立（已在缓存），**首次**进入存在窗口 —— [DS] 收尾时如实贴这两条各自实测值。

### 裁决 13 —— 🔥 「平板可添加到主屏」是**未验证项**，联网取证结论必须留在文档里

- AC 逐字：「`manifest.json` 配置正确，**平板可添加到主屏**」。
- ⚠️ **联网核实（2026-10-17）发现该 AC 在目标机型上可能是错的：** 关于 HarmonyOS 自带浏览器是否实现 W3C PWA 安装流程，公开来源**互相矛盾** —— 华为开发者联盟论坛有回复称 HarmonyOS 6 自带浏览器**未实现** PWA 安装流程，「添加到桌面」**只是生成一个网址快捷方式**，因此 `display` / `orientation` / icons 定制**均无效**；也有来源称基础 PWA 支持存在。**没有任何一条证据表明 `orientation: "portrait"` 会被读取。**
- ⇒ **1.18 的处置：**
  1. manifest **仍按标准写全**（`display: standalone`、`orientation: portrait`、192/512/maskable 图标、`theme_color`、`background_color`、`start_url`/`scope`/`id` 带 `/plantsgame/`）—— 这是唯一正确的写法，且对**用户实际使用的浏览器**可能生效。
  2. **竖屏布局不许依赖 manifest 的 `orientation`** —— 布局本身必须能在横屏/竖屏都活下来（用 `dvh` + 安全区，不锁方向）。这是已被推荐的稳妥解法。
  3. **真机验证时把「添加到主屏」单列一条**，`[DS]` 如实回填结论。**若真机证实鸿蒙自带浏览器不支持 PWA 安装**，如实降级 AC 并同步 1.19，**不得声称已验证**。
- 📎 **诚实性红线（1.11 的逐字禁令在本 story 继续有效）：**「**不许把 AC-F1 的真浏览器核对说成「离线验证已通过」**」「**「已缓存」这个前提依赖 Service Worker 缓存策略，1.18 之前不存在**」。

### ⚠️ 三条最容易照抄错的既有代码

1. **`.battle-grid` 的 `flex`** —— 它的 `flex: 0 0 auto` **不是**可以随手改的默认值，1.10 实测过 `1 1 auto` 横向撑破到 1351px。列宽问题（3px 溢出）要从 `repeat(9, 1fr)` 那里解。
