## 三、版本（**这是唯一的未决项**）

抓到的转写对应 **沪教牛津版（六三制一起）2015 试用本**（模块内编号 Unit 1/2/3）。
现行 **2024 修订版**（ISBN 9787572028809）把单元改为**全册连续编号 Unit 1–12**、
个别标题改名（`Greetings` → `Hello`、`Module 4` 改名、1B `Unit 3 Story time` → `A boy and a wolf`），
但**单元顺序与词表一致**（教习网 2024 目录逐条对得上），所以本目录两版通用。

⚠️ **另一个候选版本**：还存在更早的「上海本地版」（旧教材），其**一年级上册**词表与本目录**不同**
（本地版一上是 `one`–`ten` 十个数、**没有** `morning/afternoon`、**没有**家庭成员词、**没有** `fat/thin`；
`morning/afternoon` 在本地版二上）。一年级下册两版**逐词一致**。

**一句话判据**（用户查孩子课本 Unit 1 的 `Look and learn` 即可定版）：

- 看到 `morning / afternoon` → **一起版**（本目录对得上）✅
- 看到 `bag / book / pencil / ruler` 之类 → **旧本地版**（一上词表要另找）

## 四、可信度与已知风险

| 项 | 结论 |
|---|---|
| 词表准确性 | 两个独立来源（智慧山逐句转写 / 21cnjy 词汇表）在**一下**逐词一致；**一上**两源有上述版本级差异，无「抄错」迹象 |
| 中文释义 | 来自转写者的口语化标注（`cow 母牛` 而非 `奶牛`），**以课本印刷释义为准**，入库时按课本改 |
| 句型 | 是「逐句转写」，**混有儿歌歌词与故事台词**（部分单元转写缺板块边界标记）。生成句子卡时须人工剔除 |
| `ice cream` 这类多词术语 | 已按多词整体抽取（`ice cream 冰淇淋`），未拆词 |
| 与实体课本的偏差 | **未核对**。转写是 2015 年的第三方整理，2024 修订版是否增删个别词，只有翻书才能确认 |

## 五、入库边界

- ✅ 入库：单词表、核心句型（`Say and act` 板块的短语与句型）
- ❌ 不入库：儿歌歌词全文、故事逐句台词 —— 那是作品内容，游戏里用自己写的对应句即可
- ❌ 不入库：课本插图 —— 游戏用自绘词图（`docs/art-direction.md`）
