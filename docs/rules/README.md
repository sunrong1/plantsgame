# 工程规则 —— 单一裁决源

**这里的每条规则只写一次。** 其他任何文档（CLAUDE.md、story 文档、Dev Notes、记忆文件）
都只写 R-ID 引用，不复述正文。

违反这条不是「风格问题」，是本仓库最大的变异来源：12 个 story 文档各有一份逐字拷贝，
抄到第 4 手必然漂移，已经产出 6 类活着的错误信息。见 [R-37](process.md)。

## 怎么用

| 你要… | 去哪 |
|---|---|
| 写代码前确认架构边界 | [architecture.md](architecture.md) R-01..R-16 |
| 碰任何数值 | [range-and-balance.md](range-and-balance.md) R-20..R-24 ⚠️ 改之前先问人 |
| 记录 / 引用 / 作废一条约定 | [process.md](process.md) R-30..R-44 |
| 写测试或守卫 | [testing.md](testing.md) R-50..R-61 |
| 画词图或写 SVG | [content.md](content.md) R-70..R-78 |

**新增规则**：在本目录对应主题文件末尾追加，**不复用旧 ID**（旧 ID 永远指向旧规则）。
**修改规则正文**：直接改这里，并更新下方索引表的一句话摘要。
**删除规则**：不要删，改成「已作废」并写明被哪条取代 —— 作废记录本身有价值。

## 守卫覆盖的诚实说明

上表里 **❌ 23 条、⚠️ 5 条**（合计 **28 条**没有牙齿）。这不是本目录没写清楚，是**这些规则目前真的没有牙齿**。
（2026-10-26 夜实测：R-05 由 ⚠️ 升 ✅ ⇒ ⚠️ 减 1；⚠️ 原先写成 6 条、❌ 原先写成 24 条，
逐行点数实为 ❌ **23** 条 ⇒ 一并更正为实测值。）

其中最要紧的几条：

- **R-12（`--color-*` 值禁改）** —— 2026-10-25 夜起有守卫了：**G302** 把 18 个 `--color-*` 的**值**逐个冻结在 `tests/fixtures/color-tokens.ts` 的黄金快照里（**G301** 守个数）。
  ⚠️ **剩下的口子**：黄金快照与 `tokens.css` 是**两份**，一起改就一起绿 ⇒ 冻结的是「**只改 `tokens.css` 不许变**」，不是「**永远不许变**」（真要改色板得走 `[CC]`，并同步改快照）。
- **R-22 / R-23（平衡模拟器）** —— `[CR]` 2026-10-21（Story 2.3）从「无守卫」升为**部分覆盖**：
  R-22 有了「脚本目录里没有第二份档位字段 / 没有写死单元号」的结构守卫（G229 扩到 `scripts/`、G236），
  R-23 有了「轨迹行数 = 回合数、回合号不缺号、心数守恒」的实体守恒守卫（G237）。
  ⚠️ **剩下的口子**：没有任何测试断言该脚本的 import **指向真实 `src/core/`**，
  也没有对**僵尸容器**本身的数量守恒检查 —— 那个吞掉僵尸的 bug 出在这里，仍需人盯。
- **R-30（唯一状态源）无守卫** —— `check-execution-drift.py` 写了但没接进 `package.json`，等于不运行。状态漂移已经实际发生过一次。
- **R-50 / R-51（变异验证、断言有效性）无守卫** —— 元规则本身无法自动检查，只能靠 agent 自律。

补守卫的时机对应各自 story 的落地（见各条的「守卫」字段）。**别把这些 ❌ 当成「已覆盖」。**
