## §1 词图规格 ✅（Story 1.6 定稿）

架构 `_bmad-output/planning-artifacts/game-architecture.md:370-377` 锁了前三项，
其余由本 story（epics `:937` 明写「是否统一背景由 Story 1.6 一并确认」）定稿。

| 项 | 值 | 为什么这么定 |
|---|---|---|
| 格式 | **SVG** | 架构已锁。理由是缩放不失真 + 可 diff + 体积小。 |
| 画布 | **正方形** | 架构已锁。卡面选项是固定的方形格子，非方图要留黑边。 |
| `viewBox` | **`0 0 512 512`** | ⚠️ 架构只说「统一数值」，数值由本 story 定。取 512 而非 1000：足够 2× 屏清晰，文件仍可读可 diff。 |
| 输出尺寸 | **512 × 512**（`width`/`height` 属性也写 512） | ⚠️ 由本 story 定。**必须与 `viewBox` 一致**：不一致时浏览器按 CSS 拉伸，图会糊。 |
| 背景 | **透明底，不画统一背景** | ⚠️ 由本 story 定。理由见下。 |
| 文件名 | **= 词条 id**（如 `u1-dog.svg`） | 架构已锁。校验器强制：文件名与 id 不符即报错。 |
| 目录 | `public/assets/words/unit-<NN>/<entryId>.svg` | 按单元分层，避免 200–400 张图挤在一个目录。 |
| URL | `/assets/words/unit-01/u1-dog.svg` | `imageSrc` 在内容 JSON 里就是这个字符串。 |

### 为什么「透明底 + 不统一背景」

1. **卡片本身已经有底**（`--color-correct` / `--color-wrong` 反馈色就画在选项格上）。
   图再自带一块背景 = 两层底色叠加，答对时的绿会被吃掉，孩子看到的反馈色不再等于规格色。
2. **「统一背景」与「透明底」在本题里不是两个选项**：统一背景必然是不透明的，
   而 Story 2.1 的程序化生成评估（GDD `:616`「是否需要透明底，决定能否复用/程序化生成」）
   以 SVG + 透明底为**必要前提** —— 不透明背景的图没法按主体抠轮廓。
3. **代价是明确的**（写在这里而不是等美术踩）：同一批词图的「重心」不统一，
   孩子在四张图之间比较时，注意力会先落到「哪个东西画得大」而不是「哪个是 dog」。
   → 这正是 §3「构图规范」要解决的问题，**归属 Story 1.7**：届时规定
   主体占画布的比例区间（如 60%–75%）、留白、以及是否统一视角。

### 占位图说明

`public/assets/words/unit-01/*.svg` 目前是 **30 张程序生成的占位图**
（对角线灰纹 + 虚线框 + `PLACEHOLDER` 字样），**不是美术成品**，
Story 1.8 / 1.9 会逐张替换。占位图的存在只是为了让
「词图缺失」这一类内容错误在本 story 就**真正可验证** ——
没有占位图，校验器只能恒退 0，重演「跑过了不构成任何证据」的老问题。

## §2 色板 ✅（Story 1.6 定稿）

实现在 `src/styles/tokens.css`（CSS 变量），实测在 `tests/content/palette.test.ts`。

### 三条选色规则（先于具体色值）

1. **三个塔型两两色相间隔 ≥ 60°** —— 这是「孩子看得出哪株是哪株」的**主机制**。
2. **每个元素与它所在底色的对比 ≥ 3:1** —— 塔在草地上、僵尸在路径上。
   于是三个塔型都被压在 L ≤ 0.09 的深色区，塔面白字才有 ≥ 4.5:1。
3. **永远成对出现的两种颜色**（答对/答错）另按色相 ≥ 90° 分。

### 色值表（L = WCAG 相对亮度，H = 色相角度）

| token | 值 | 用途 | L | H |
|---|---|---|---|---|
| `--color-bg` | `#7cb342` | 草地底色 | 0.369 | 89° |
| `--color-path` | `#d7ccc8` | 僵尸行走的浅土路径 | 0.618 | 16° |
| `--color-tower-shooter` | `#09428c` | 直射塔（深蓝） | 0.058 | 214° |
| `--color-tower-slow` | `#6a1b9a` | 减速塔（紫） | 0.062 | 277° |
| `--color-tower-aoe` | `#7a3200` | 范围塔（深橙） | 0.064 | 25° |
| `--color-zombie` | `#1b5e20` | 僵尸（深墨绿） | 0.083 | 124° |
| `--color-sun` | `#fdd835` | 阳光（亮黄） | 0.703 | 49° |
| `--color-heart` | `#e53935` | 心（红，HUD 专用） | 0.198 | 1° |
| `--color-correct` | `#2e7d32` | 答对反馈（绿） | 0.155 | 123° |
| `--color-wrong` | `#b71c1c` | 答错反馈（红） | 0.110 | 0° |
| `--color-overlay-range` | `rgba(255,255,255,0.3)` | 射程高亮 | — | — |
| `--color-on-tower` | `#ffffff` | 塔面文字 | — | — |

**僵尸为什么是墨绿**：三个塔型占了 214° / 277° / 25°，色环上只剩
「25°→214°」这一段（189°）能同时离三个塔 ≥ 60°，中点落在绿青色域。
僵尸用深墨绿（L 0.083）压住，与草地（0.369）对比 3.14:1、与路径（0.618）对比 5.01:1。

### 实测对比度（`palette.test.ts` 逐条守着）

| 关系 | 实测 | 门槛 |
|---|---|---|
| 直射 ↔ 减速 色相差 | 63.4° | ≥ 60°（护栏 ≥ 62°） |
| 直射 ↔ 范围 色相差 | 170.7° | ≥ 60° |
| 减速 ↔ 范围 色相差 | 107.3° | ≥ 60° |
| 直射 / 减速 / 范围 ↔ 草地 | 3.86 / 3.75 / 3.67 | ≥ 3（护栏 ≥ 3.3） |
| 塔面白字 ↔ 三塔底色 | 9.68 / 9.39 / 9.20 | ≥ 4.5 |
| 僵尸 ↔ 路径 / 草地 | 5.01 / 3.14 | ≥ 3 |
| 路径 ↔ 草地 | 1.59 | ≥ 1.5 |
| 答对 ↔ 答错 色相差 | 123°（明度差 0.045） | ≥ 90° |
| 阳光 ↔ 草地 色相差 | 40.3° | ≥ 30°（**例外，非 3:1**，见取舍 3） |

### 三条已知的取舍（不是遗漏）

1. **塔与塔之间没有 3:1 的明度对比，只有色相。** 这不是漏做，是色域里做不到：
   要让每个塔与草地 ≥3:1，三个塔必须都落在 L ≤ 0.09；而深色区内任意两色要拉开 3:1，
   需要 9 倍明度跨度（0.087 → 0.039 → 0.004），第三个只能是近黑 ——
   那既不像塔，也会和路径、阴影糊在一起。
   ⇒ **代价**：灰度打印或完全色觉障碍下三塔不可分。
   **兜底责任在 Story 1.7**：美术必须另外提供形状/轮廓差异，不能只靠颜色区分塔型。
2. **路径与草地只有 1.59:1。** 门槛取 1.5 而非 3.0，是因为两块各有几十像素高的**区域**，
   WCAG 1.4.11 的 3:1 是给小元件与图形边界的；区域边界靠位置已经分得开，
   这里的诉求只是「一眼看出路径不是草地」。**Story 1.7 需在真机截图上复核这一条。**
3. **阳光是唯一不适用「对底色 ≥ 3:1」的棋盘元素** —— 这条判据对它**数学上不可达**：
   草地 L = 0.369，要对它达到 3:1 需要 `L_sun ≥ 1.208`（>1，不可能）或
   `L_sun ≤ 0.090`（深棕 —— 那就不叫阳光了）。
   ⇒ 硬套 3:1 只会逼着人把阳光改成深棕：**拿一个「可达的坏方案」换一条「错的规则」**，
   这是本项目明确拒绝的交易。改按**色相间隔 ≥ 30°** 查：亮黄 49° vs 草地绿 89°，
   间隔 40°，肉眼分得开；另加一条 `对比度 ≥ 1.5:1` 的保底，
   防止有人把阳光调成草地色而「无懈可击地」豁免掉。
   （`--color-heart` 同样是例外，但它是纯 HUD 元素不上棋盘，性质不同。）

## §3 构图规范 ⏳（Story 1.7）

**本节尚未撰写。** Story 1.6 只定了 §1 的机器可校验部分（格式 / 尺寸 / 命名 / 底色）
与 §2 的色板；构图属于**美术判断**，必须与真机上的可辨认性一起试出来，
在平板上对着实际尺寸的照片评审比在文档里拍板可靠。

Story 1.7 需要在这里补上（至少）：

- 主体占画布的比例区间与统一视角（正侧面 3/4 侧？）—— §1 已经点明，
  没有它，四张图的「重心不一」会让孩子先比大小再比内容。
- 词图之间的留白与视觉密度（避免某些词一眼就认出、某些要盯很久）。
- 塔图 / 僵尸图的**形状差异**（见 §2 取舍 1 的兜底责任）。
- 真机截图复核：路径/草地边界（1.59:1）在 6.5 岁孩子的实际观看距离下是否够。
