# 地图视觉优化设计方案

**日期**: 2026-05-23
**类型**: 视觉增强

## 概述

为改善 530x350 地图的视觉效果，添加格子高亮和僵尸入侵箭头两种视觉增强。

## 设计方案

### C. 格子高亮效果

- **触发**: 鼠标悬停
- **空地高亮**: `#90EE90` (浅绿)
- **已占用高亮**: `#FFB6C1` (浅粉)
- **边框宽度**: 2px
- **透明度**: 80%
- **行为**: 悬停时显示，移开时消失

### D. 僵尸入侵箭头

- **位置**: 地图左侧边缘（第 0 列左侧）
- **样式**: 简约三角形箭头
- **颜色**: `#2F4F4F` (深暗色)
- **大小**: 覆盖 5 行高度，居中
- **状态**: 静态显示

## 实现计划

1. 在 `GridManager` 中添加悬停检测
2. 使用 Graphics 对象绘制高亮边框
3. 在 `BootScene` 中创建箭头纹理
4. 在 `PlayScene` 中渲染箭头（在植物层下方）
