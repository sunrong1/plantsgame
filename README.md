## 功能特性

### 核心玩法
- **5×9 草坪网格** - 策略性植物布局
- **4 种植物** - 豌豆射手、向日葵、坚果墙、樱桃炸弹
- **2 种僵尸** - 普通僵尸、旗帜僵尸
- **3 波僵尸进攻** - 递增难度曲线

### 游戏系统
- 阳光资源管理（天空掉落 + 向日葵产出）
- 植物种植预览系统（绿色/红色指示）
- 智能豌豆攻击判定（只攻击同一行右侧僵尸）
- 僵尸 AI 寻路与攻击
- 樱桃炸弹范围爆炸
- 游戏胜利/失败判定
- 教程引导面板

### 技术亮点
- **数据驱动设计** - 植物/僵尸参数独立配置，易于调平衡
- **分层架构** - 配置层、实体层、系统层、场景层分离
- **TypeScript 类型安全** - 完整接口定义
- **Vite 快速开发** - HMR 热更新
- **Vitest 单元测试** - 81 个测试用例覆盖配置和数值平衡

## 快速开始

### 环境要求
- Node.js 18+
- npm 9+

### 安装与运行

```bash
# 克隆项目
git clone https://github.com/sunrong1/plantsgame.git
cd plants-game

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

访问 http://localhost:5173 开始游戏。

### 运行测试

```bash
npm test
```

### 构建生产版本

```bash
npm run build
npm run preview
```

## 项目结构

```
src/
├── main.ts                 # 游戏入口
├── config/                 # 配置数据 (植物、僵尸、波次)
│   ├── game.ts            # 游戏配置
│   ├── plants.ts          # 植物配置
│   └── zombies.ts          # 僵尸配置
├── types/                  # TypeScript 类型定义
│   └── index.ts
├── entities/              # 游戏实体
│   ├── Plant.ts          # 植物实体类
│   ├── Zombie.ts         # 僵尸实体类
│   └── Projectile.ts     # 豌豆子弹
├── systems/              # 游戏系统
│   ├── GridManager.ts    # 草坪网格管理
│   ├── WaveManager.ts   # 波次管理
│   └── EconomyManager.ts # 阳光经济
└── scenes/              # Phaser 场景
    ├── BootScene.ts     # 加载场景
    ├── PlayScene.ts     # 主游戏场景
    └── UIScene.ts       # UI 叠加层
```

## 游戏操作

| 操作 | 说明 |
|------|------|
| 点击植物卡片 | 选中该植物 |
| 点击草坪格子 | 种植选中的植物 |
| ESC / 右键 | 取消选择 |
| 点击阳光 | 收集阳光 |

## 数值平衡

| 资源 | 数值 |
|------|------|
| 初始阳光 | 150 |
| 天空掉落 | 每 10 秒 +25 |
| 向日葵产出 | 每 5 秒 15~35 |
| 阳光消失时间 | 8 秒 |

| 植物 | 成本 | HP | 攻击/产阳光 |
|------|------|-----|------------|
| 豌豆射手 | 100 | 100 | 20 伤害 / 1.5秒 |
| 向日葵 | 50 | 100 | 25±10 阳光 / 5秒 |
| 坚果墙 | 50 | 400 | 阻挡 |
| 樱桃炸弹 | 150 | 100 | 消灭整行僵尸 |

| 僵尸 | HP | 速度 | 攻击 |
|------|-----|------|------|
| 普通僵尸 | 100 | 1格/1.5秒 | 20 / 秒 |
| 旗帜僵尸 | 200 | 1格/1.5秒 | 20 / 秒 |

| 波次 | 延迟 | 数量 | 间隔 |
|------|------|------|------|
| 第1波 | 20秒 | 6只 | 2.5秒 |
| 第2波 | 30秒 | 10只 | 1.8秒 |
| 第3波 | 30秒 | 18只 | 1秒 |
